Llama 3.1 8B Instruct

Usage : Local et cloud

Tarif : Gratuit (poids open) / coût infra si hébergé

Supports : Ollama, LM Studio, vLLM, Transformers

Variantes : 8B, 70B

Avantages : Bon équilibre qualité/performance, large écosystème

Inconvénients : 70B exige une machine puissante

Mistral Nemo Instruct

Usage : Local et cloud

Tarif : Gratuit (open weights)

Supports : Ollama, vLLM, llama.cpp

Variantes : 12B

Avantages : Très bon ratio qualité/vitesse en local

Inconvénients : Moins performant que les plus gros modèles sur tâches complexes

Voir le modèle

Qwen2.5 Instruct

Usage : Local et cloud

Tarif : Gratuit (open weights)

Supports : Ollama, Transformers, vLLM

Variantes : 7B, 14B, 32B, 72B

Avantages : Très polyvalent, bon multilingue

Inconvénients : Les grandes variantes consomment beaucoup de VRAM

Voir le modèle

Gemma 2

Usage : Local et cloud

Tarif : Gratuit (licence ouverte)

Supports : Ollama, Kaggle, Vertex AI

Variantes : 9B, 27B

Avantages : Bonne qualité générale et intégration Google

Inconvénients : Nécessite optimisation pour certains usages locaux
