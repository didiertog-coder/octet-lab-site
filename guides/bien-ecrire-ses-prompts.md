Une demande floue donne une réponse floue. Quatre éléments suffisent à améliorer nettement les résultats, avec n'importe quel assistant.

## La méthode

- **Contexte** : qui vous êtes, pour qui, dans quel but. « Je prépare une présentation pour des collègues non techniques. »
- **Tâche** : une action précise. « Résume ce texte en cinq points. »
- **Format** : longueur, structure, ton. « Un tableau de trois colonnes, ton neutre. »
- **Exemple** : un modèle de ce que vous attendez, s'il existe.

## Exemple complet

```
Je gère une petite boutique en ligne de matériel informatique.
Rédige une fiche produit pour un SSD NVMe de 1 To.
Format : 3 phrases d'accroche, puis 5 points techniques.
Ton : clair, sans superlatifs.
```

## Bons réflexes

- Découpez les gros travaux en plusieurs étapes plutôt qu'une seule demande géante.
- Demandez à l'IA de poser ses questions si une information manque.
- Relisez toujours : une IA peut se tromper, surtout sur les chiffres, les noms et les références.
- Ne collez jamais de données personnelles ou confidentielles dans un service en ligne.
