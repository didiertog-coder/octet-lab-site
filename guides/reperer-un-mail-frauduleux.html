Repérer un mail frauduleux et réagir

Le phishing reste l’attaque la plus rentable pour les cybercriminels : simple à lancer, efficace, et souvent convaincante. La défense ne repose pas sur un “truc magique”, mais sur une méthode courte, répétable et appliquée systématiquement.

Objectif du guide

Vous apprendrez à :

  • identifier les signaux de phishing en moins de 60 secondes ;
  • vérifier un message sans vous exposer ;
  • appliquer un protocole de réaction si vous avez cliqué.

Méthode experte “STOP-VERIFY-ACT”

1) STOP : repérer les signaux de manipulation

Signaux fréquents :

  • urgence forte (« dernier rappel », « compte bloqué ») ;
  • menace implicite (amende, suspension, perte d’accès) ;
  • récompense trop belle (remboursement inattendu, cadeau) ;
  • ton inhabituel par rapport à l’organisme.

Le but de l’attaquant est de vous faire agir vite, sans vérifier.

2) VERIFY : contrôler sans cliquer

Vérifications essentielles :

  • inspecter l’adresse complète de l’expéditeur ;
  • survoler les liens sans cliquer ;
  • vérifier domaine et orthographe ;
  • ouvrir le service concerné via votre chemin habituel (appli, favori, URL tapée).

Règle d’or : ne jamais valider un message depuis le message lui-même.

3) ACT : réagir immédiatement en cas de clic

Si vous avez cliqué ou saisi des identifiants :

  • changez le mot de passe du compte concerné ;
  • changez aussi les mots de passe réutilisés ailleurs ;
  • activez la double authentification ;
  • révoquez les sessions actives si possible ;
  • surveillez l’activité du compte (emails, connexions, paiements).

Si données bancaires concernées : contactez la banque immédiatement.

4) SIGNALER : protéger les autres

Canaux utiles en France :

  • signal-spam.fr (emails) ;
  • 33700 (SMS spam/fraude) ;
  • internet-signalement.gouv.fr (contenus illicites) ;
  • cybermalveillance.gouv.fr (aide et diagnostic).

Signaler aide aussi à améliorer le filtrage global.

5) Prévenir les prochains incidents

Mesures simples et efficaces :

  • gestionnaire de mots de passe ;
  • mots de passe uniques par service ;
  • MFA partout où possible ;
  • mises à jour navigateur/OS régulières.

La prévention réduit drastiquement l’impact d’un clic accidentel.

Checklist anti-phishing personnelle

  • [ ] Je ne clique jamais sous pression
  • [ ] Je vérifie toujours expéditeur + lien
  • [ ] J’ouvre les services via URL connue
  • [ ] MFA activée sur comptes critiques
  • [ ] Mot de passe unique par service
  • [ ] Procédure de réaction connue

Erreurs fréquentes

  • Vérifier “vite fait” en cliquant quand même.
  • Croire qu’un logo officiel suffit.
  • Réutiliser le même mot de passe partout.
  • Ignorer l’incident après un clic.

FAQ rapide

Un mail sans faute peut-il être frauduleux ?

Oui. Les campagnes modernes sont souvent très bien rédigées.

Les pièces jointes PDF sont-elles toujours sûres ?

Non. Même un PDF peut contenir des pièges (liens, scripts selon contexte).

Le mobile est-il moins exposé ?

Non. Le phishing fonctionne très bien sur mobile car les URLs sont moins visibles.

Que faire si je ne suis pas sûr ?

Ne cliquez pas. Vérifiez via un canal indépendant.

Conclusion

Face au phishing, la vitesse de réaction doit venir après la vérification. Avec une routine simple (Stop, Verify, Act), vous réduisez fortement le risque et limitez l’impact en cas d’erreur.
