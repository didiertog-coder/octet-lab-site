Choisir un nom de domaine et un hébergement

Le nom de domaine

C'est votre adresse (monsite.fr), que vous louez à l'année auprès d'un registrar.

  • Court, facile à dire et à écrire, sans tirets ni chiffres.
  • Choisissez .fr pour un public français, .com pour un public international.
  • Vérifiez que le nom n'est pas une marque déposée (base de l'INPI).
  • Gardez la gestion du domaine dans un compte à vous, séparé de l'hébergement : vous pourrez changer d'hébergeur sans perdre l'adresse.
  • Comparez le prix du renouvellement, pas seulement celui de la première année.

L'hébergement

  • Site de guides, blog, portfolio : un hébergement statique (GitHub Pages, Cloudflare Pages, Netlify).
  • Site avec base de données ou WordPress : un hébergement mutualisé ou un VPS.
  • Application avec comptes utilisateurs : un VPS ou une plateforme applicative.

Points de contrôle

  • HTTPS inclus et gratuit.
  • Sauvegardes disponibles si le site n'est pas statique.
  • Localisation des serveurs dans l'Union européenne si vous traitez des données personnelles.
  • Possibilité d'exporter votre site facilement.
